# 语文学期末论文研究｜《额尔古纳河右岸》

## 暂定论题
**《额尔古纳河右岸》中人物记忆的选择性**

**核心问题：** 叙述者为什么重点回忆某些人物及其经历？这些叙述选择有什么意义？

## 阅读关注点
1. **选择：** 回忆了谁、什么经历？哪些内容详写或略写？
2. **叙述评价：** 叙述者如何理解和评价人物命运？是否由此呈现生命经验？
3. **辅助观察：** 人物命运与前文细节是否存在伏笔或事后照应？不能把照应直接当成有意伏笔。

## 当前可追踪的文本
- **第11页：** 不愿说出氏族姓氏——较明确的叙述选择。
- **第27—34页：** 列娜之死及镜子——记忆重点及叙述的后续延伸。
- **第38—41页：** 林克狩猎——叙述者对自身与他人的比较。
- **第48—52页：** 达西之死——叙述者如何评价他人的幸福。

## 尚待证实
- 猎鹰是否象征民族文化流失；
- 列娜之死是否与民族衰亡、宿命有关；

- 详写人物是否足以证明叙述者主动选择记忆。
